# プライバシー

更新日：2026-11-26

紹介サイトと、端末で動くアプリ。データの行き先を分けて説明します。

## 紹介サイト

この紹介サイトには、独自のアクセス解析、広告、ログイン、問い合わせフォームを設けていません。アプリの会話、API キー、録音をこのサイトへ送る機能も設けていません。コマンドのコピー操作はブラウザ内で行います。

GitHub Pages で公開する場合、GitHub はセキュリティ目的で閲覧者の IP アドレスを記録・保存すると説明しています。GitHub の取得情報や保持方針は同社のプライバシーステートメントを参照してください。「情報が一切取得されないサイト」という意味ではありません。

## 端末に保存する情報

アプリは設定、会話履歴、下書き、添付、プロジェクト情報などを端末内の保存先に保持します。現行ソースは Pi の既存設定を共有する場合があり、独立した既定の保存先への切り替えは候補段階です。試用時は README のとおり、アプリと Pi の両方へ専用の保存先を指定してください。

API キーの暗号化と、設定画面へキーを返さない操作は試作の結果であり、通常のアプリへの製品実装は未完了です。キーが平文の設定に保存され、画面側へ渡る経路があります。

## モデルや外部ツールへ送る情報

会話、選択した添付、ツールの実行結果などは、設定したモデルサービスへ送信される場合があります。タイトル生成、引き継ぎ下書き、要約、モデル一覧の取得なども外部通信を伴います。送信先の条件、保管期間、学習利用の有無は各サービスの案内を確認してください。

拡張・MCP・子プロセスは、その機能や設定に応じて追加のファイル参照・通信を行う場合があります。保守者のサーバーを通らないことが、外部に送信されないことを意味するわけではありません。

## 音声入力とダウンロード

標準の音声入力では、録音データを端末内の Whisper 実行部へ渡して文字起こしします。録音を外部の音声認識 API へ送る実装ではありません。認識したテキストを会話として送信すると、通常のモデル接続先へ送られます。

初回のモデル取得や実行部のビルドには、モデル配布元や GitHub などとの通信が必要です。取得後の文字起こしは端末内で行います。外部拡張が追加した音声機能は、この説明の対象とは別に確認してください。

## Pi 本体の通信設定

Pi 1.4.0 の公式文書には、匿名のインストール・更新報告と一部プロバイダーへの属性ヘッダーを enableInstallTelemetry、分析への参加を enableAnalytics として説明する設定があります。文書上の既定は前者が有効、後者が無効です。GUI と同梱 SDK のすべての通信経路を監査し終えたという意味ではありません。

試験用のプロセスでは PI_TELEMETRY=0 でインストール・更新報告と属性ヘッダーを無効にできます。更新確認やモデル通信は別です。詳しくは Pi の設定文書と本リポジトリの導入案内を参照してください。

## 更新確認

現行ソースには、開発モード以外で上流 pi-gui の GitHub Releases を定期的に確認する処理が残っています。この通信は独立版の自動更新が実装済みであるという意味ではありません。外部サイトを開く操作や認証時の通信も、対応するサービスへ接続します。

## Issues・投稿・問い合わせ

連絡先はこのリポジトリの保守者です。GitHub に自ら投稿したアカウント情報や本文は、不具合の調査、改善、投稿への対応のために参照される場合があります。公開の Issues や Pull Request は他の人にも閲覧できます。実キー、個人の会話、実データを含むログは投稿しないでください。

投稿の編集・削除は GitHub の機能と方針に従います。一般的な問い合わせは Issues、脆弱性の連絡は SECURITY.md の案内を参照してください。このサイトに非公開の問い合わせ窓口を設けたという意味ではありません。

## 説明の更新

新しい解析機能、フォーム、データ送信先、ホスティングを追加する場合は、その実装と案内を合わせて更新します。この文書は当日時点の実装と公開構成を説明するもので、任意の改造版や外部拡張まで保証しません。
