# サポートと連絡

一般的な質問と不具合は、このリポジトリの Issues で受け付けます。公開の場であるため、キー、認証ファイル、個人の会話、実データを含むスクリーンショットやログを投稿しないでください。

不具合の報告には、対象のコミット、OS と Node・pnpm の版、再現する操作、期待した結果、実際の結果を記載してください。ダミーキー、架空のテキスト、一時プロファイルで再現できる形を推奨します。

保守者は任意の範囲で対応します。回答・修正の期限、すべての環境への対応、個別の改造の代行を保証するものではありません。脆弱性は [SECURITY.md](../SECURITY.md) の案内に従ってください。
