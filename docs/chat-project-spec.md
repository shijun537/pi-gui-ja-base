# チャットとプロジェクトの追加仕様

2026-11-19 に合意した Windows x64 向けの仕様。利用者は気軽に相談を始め、具体的な作業が決まった段階で、相談内容を対象プロジェクトへ引き継げる。実装の検証状況は [開発進捗](development/progress.md#最新の検証) を参照する。

## 1. フォルダ不要のチャット

- 起動後に「チャット」から質問、壁打ち、文章作成を始められる。登録済みフォルダがゼロでも利用できる。
- 接続済みのモデルを使う。モデルが未接続の場合は接続設定へ案内する。
- 会話は履歴から開き直せる。エージェントによる作業フォルダの読み書きとコマンド実行は、対象フォルダを選んだプロジェクト作業で有効にする。

## 2. チャットからプロジェクトへ引き継ぐ

「プロジェクト」から直接フォルダを開いて作業を始められる。チャットで決めた方針を使う場合は、次の順に進む。

1. チャットで「プロジェクトで続ける」を押す。
2. 作業するフォルダを選ぶ。
3. 引き継ぐ会話の要点と作業依頼を下書きで確認し、必要に応じて編集する。「AI で要点を下書き」は、直近のテキストのやり取りをチャットのモデルで要約する。下書きは直接入力することもできる。
4. 送信すると、新しいプロジェクトのスレッドが始まる。Pi は選択したフォルダで調査や編集を行い、利用者は差分を確認できる。

元のチャットは履歴に残り、利用者は相談の経緯に戻れる。途中で取り消した場合は元のチャットに戻る。新しい入口と引き継ぎ操作は、表示言語の設定に合わせる。

## 3. Pi のバージョンに合わせて保守する

- Windows アプリの仕様とリリースはこの独立リポジトリで管理する。[元の pi-gui](https://github.com/minghinmatthewlam/pi-gui) はコードの出典とし、著作権表示と [MIT ライセンス](../LICENSE) を保持する。
- 継続して互換性を追う先は [Pi](https://github.com/earendil-works/pi)。関連する Pi パッケージの版をそろえ、Windows で検証を通過した組み合わせを固定して取り込む。
- Pi の動作を利用し、バージョン間の互換処理は `packages/pi-sdk-driver` に集約する。アプリの配布案内には、検証済みの Pi の版を記載する。 [現在の設計](architecture.md#pi-adapter-and-contracts)

## Windows での確認条件

| 場面      | 確認する動作                                                                                                   |
| --------- | -------------------------------------------------------------------------------------------------------------- |
| 初回利用  | フォルダ未登録の状態でモデルを接続し、チャットに最初のメッセージを送れる。                                     |
| 再起動    | チャットを履歴から開き、続きのメッセージを送れる。                                                             |
| 引き継ぎ  | 対象フォルダと下書きを確認して送信すると、選んだフォルダでプロジェクト作業が始まる。元のチャットを開き直せる。 |
| Pi の更新 | 既存の会話を開き、送信・停止・再開とプロジェクト内のツール実行を確認できる。                                   |
