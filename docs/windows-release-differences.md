# 元の pi-gui からの変更点

2026-11-19 時点の Windows x64 向け配布案。元の [pi-gui](https://github.com/minghinmatthewlam/pi-gui) をもとにしています。

## 利用者向けの案内文

> **設定画面を日本語で使えます。** 英語表示から切り替えるときは「Settings → Appearance → Language」で「日本語」を選びます。「システムに合わせる」を選ぶと、Windows の表示言語に従います。日本語表示に対応しているのは、設定の各ページ、設定内のメニュー、アプリに戻るボタンです。

開発者向けの変更として、ソースを共有する前に個人情報の混入を見つけるための検査を追加しました。検査はソースを扱う開発工程で実行します。 [日本語表示の対象](../apps/desktop/src/i18n/AGENTS.md#coverage) [個人情報ガードの検証](development/fork-review-status.md#採用範囲と判断)

## 採用の判断が残る Windows の変更

以下の変更は作業ツリーにあり、配布版への採用は未決定です。

| 変更                     | 採用した場合の利用者向け説明                                                                 |
| ------------------------ | -------------------------------------------------------------------------------------------- |
| 設定などの保存           | ファイルが別の処理に使われていて書き換えが失敗した際に、元の保存内容を残すよう改善しました。 |
| Git の差分レビュー       | Windows で追加・削除したファイルの変更内容を表示する処理を改善しました。                     |
| 会話ターン前後の状態記録 | 作業フォルダ内のファイルをまとめて記録するようにし、変更を振り返るための処理を改善しました。 |

実装箇所は [保存処理](../apps/desktop/electron/persistence/atomic-file-write.ts)、[差分レビュー](../apps/desktop/electron/platform/files/git-review.ts)、[作業状態の記録](../apps/desktop/electron/workbench/checkpoint-store.ts) を参照してください。

## 性能を紹介するときの根拠

2026-11-19 に Windows の現行作業ツリーで `pnpm check` を実行した際、合成500ファイルの作業状態の記録は約2.1秒でした。2,000ファイルでは既定の2秒以内に完了せず、時間上限を延ばしたテストで約3.9秒で完了しました。旧実装の約53.8秒という記録は同条件で再現できていないため、新旧の速度差は未確定です。 [計測に使ったテスト](../apps/desktop/tests/unit/checkpoint-store.spec.ts) [旧実装の計測記録](../ARCHIVE/2026-11-18-expanded-handoff.md#6-計測と未再検証の項目)

アプリを開いて操作できるまでの時間は、新旧を同条件で計測できていません。配布時に性能へ言及する場合は、実測した作業状態の記録に限定します。

## 配布時に確定すること

現在の承認済み13ファイルは、日本語設定、開発時の個人情報ガードと、その組み込みに関する変更です。Windows 向けの保存・レビュー・状態記録を案内文に加える場合は、採用した構成の Windows x64 版で動作を確認します。 [検品管理表](development/fork-review-status.md) [上流の MIT ライセンス](../LICENSE)
