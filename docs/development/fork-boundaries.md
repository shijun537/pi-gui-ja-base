# このフォークの作業範囲

ローカルの親フォルダで使っていた作業規則のうち、このリポジトリだけで作業を再開するために必要な内容を記載する。新しい規則や承認段階を追加するものではない。

- 対象は Pi-GUI の画面、Electron の処理、Pi への連携、サイト、例、検証基盤と文書。Pi 本体や `node_modules` 内の Pi コードへパッチを当てない。
- `packages/pi-sdk-driver` は薄いアダプターとして保つ。private API の互換処理は既存の互換境界に閉じ込める。Pi の版を変更する場合は先に利用者へ確認する。
- Pi が管理する設定とセッションの形式を互換性なく書き換えない。利用者の普段の共有設定は変更せず、試験には専用プロファイルと合成データを使う。
- 実キー、OAuth トークン、認証ファイル、実ユーザーの会話や個人情報を読み出し・コピー・ログ出力・公開しない。検査結果を報告するときも検出値は出力しない。
- ユーザーの履歴、キャッシュ、画像、一時成果物を承認なく削除・上書き・外部送信しない。
- renderer・preload・main・contracts の境界は [アーキテクチャ](../architecture.md) に従う。境界検査を弱めて通過させない。
- 現在のブランチと作業ツリーを尊重し、利用者の明示がなければブランチの変更や履歴の書き換えをしない。
- 変更の共有とコミット前に既存の混入検査を行う。GUI の変更は実 Electron でも確認し、検証した版・条件・未確認の範囲を区別する。既存の結果は同じ差分と条件に限って再利用する。
