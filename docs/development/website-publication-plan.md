## 案内の範囲

このサイトは無料 OSS の紹介であり、アカウント登録、決済、問い合わせフォーム、独自の解析サービスは追加しない。MIT の改変・再配布の権利に、利用案内から追加制限を課さない。法令への適合を保証する表現や、存在しない会社情報、サポート窓口、応答期限は記載しない。

プライバシーは、静的な紹介サイト、GitHub のホスティング・投稿、利用者の端末にあるアプリ、外部モデル・拡張・ダウンロード元を分けて説明する。製品版のキー暗号化や OS 隔離が完成済みとは案内しない。

## 送信経路の開始時確認

指定の空の公開リポジトリと push 権限を GitHub 連携で確認した。通常の Git 通信は `github.com` の名前解決で停止した。GitHub 連携はファイルや Git オブジェクトを操作できるが、ローカルの履歴一式を空のリポジトリへ転送する専用操作は提供していない。既存の候補と上流履歴を保持し、実行できた送信方法と残件を記録する。

## 送信とサイト公開の方法

通常の Git 通信が使えないため、指定先の空リポジトリを LICENSE から初期化し、GitHub 連携で必要なソースを送信する。公開上流の固定コミットを GitHub Actions で取得し、既存の公開ソースを変えない形で履歴へつなぐ手順も用意した。履歴の接続は workflow の成功と実際の祖先を確認してから完了とする。元のローカルの履歴と候補は保持する。

紹介ページは GitHub Pages 用の静的出力を生成する。`website-pages.yml` はサイトをビルド・検査して静的ファイルだけをアップロードし、Pages が設定済みなら公開する。未設定の場合は「ビルド済み・公開待ち」と記録する。新しい認証トークンは作らず、Pages の設定を確認できない状態を公開成功とは扱わない。

Pages の初回設定が必要な場合は、リポジトリの Settings → Pages → Source を GitHub Actions にし、Japanese introduction site workflow を実行する。実際の公開 URL と結果を確認するまで、この記録や README では公開済みと案内しない。
