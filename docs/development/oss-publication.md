# OSS のソース公開：push までの計画と実行記録

2026-11-26。利用者の指示により、開発中の独立フォークとしてのソース公開を先行する。Windows 正式配布の完成とは別に扱う。

## 公開候補の範囲

現在の共有作業ツリーを基礎とし、公開対象をファイル一覧で照合する。日本語化、チャットと引き継ぎ、承認、音声入力、Windows の保存・レビュー・検証基盤の変更と、それを支える試験・文書を対象にする。初期の13ファイルだけの検品結果を、今回の全差分の検証結果として扱わない。

専用コピーだけの送信先照合・暗号化・Electron 44・セットアップ・独立版識別子の候補は取り込まない。共有ソース内の合成データによる保護試作テストは、製品機能と区別して扱う。API キー、実ユーザーの設定、セッション、試験用プロファイル、実行ログ、生成済み配布物は公開対象外。

Pi の版と本体は変更しない。上流の履歴とライセンスを維持し、公開のために既存履歴を書き換えない。元の作業ツリーのブランチは変更しない。

## 別の環境で再確認する手順

Node.js 22.19 以上と pnpm 10.25.0 を使い、このリポジトリのルートで実行する。実キーや普段の Pi 設定は使用しない。保存先の環境変数は、この PowerShell の子プロセスに適用する。

```powershell
$validationProfile = Join-Path ([System.IO.Path]::GetTempPath()) ([guid]::NewGuid().ToString())
$env:PI_APP_USER_DATA_DIR = Join-Path $validationProfile 'app'
$env:PI_CODING_AGENT_DIR = Join-Path $validationProfile 'agent'
$env:PI_APP_REAL_AUTH = '0'
corepack pnpm install --frozen-lockfile
corepack pnpm check
corepack pnpm --filter @pi-gui/desktop run build
$env:PI_APP_TEST_LANE = 'core'
$env:PI_APP_TEST_MODE = 'background'
corepack pnpm exec playwright test -c apps/desktop/playwright.config.ts apps/desktop/tests/core/folderless-chat.spec.ts apps/desktop/tests/core/windows-application-menu.spec.ts
```

全体検査が失敗した場合は、成功した段階と停止した試験を分けて記録する。上の手順は実サービスや OS のクリップボード操作を検証するものではない。音声入力の再確認には、README に記載した Whisper 実行部とモデルの準備も必要。
