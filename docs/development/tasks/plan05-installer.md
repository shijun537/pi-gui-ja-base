# 計画05: Windows セットアップと配布候補の検証

更新日: 2026-11-26。計画05は継続中。ショートカット選択の専用試作、共有ソースの GitHub CI、最終配布候補を分けて管理する。

## 今回の担当範囲と結果

既存の計画05チャットへ接続できないため、共有済みの記録と専用コピーを読み取り調査し、接続回復後の検証を準備した。アプリやセットアップの製品実装は変更していない。新たなインストール、アンインストール、残存物の削除、保護設定の変更は実行していない。利用者提供の保護ソフトの CSV・画面画像は参照していない。

| 専用コピーの v2 パッチと `installer.nsh`     | パッチに含まれる追加ファイル47行と専用コピーが一致。NSIS 設定4項目も照合した                                 | 静的照合の成功。生成済み EXE がこのソースから作られたことの新たな証明ではない                 |

読み取り専用の補助、実行結果、保護設定を維持する検証行列はローカル試験資料として保存した。公開文書には個人のパス、生ログ、既存チャットの識別子を含めない。

補助スクリプトの構文確認と、別のルートを指定した際の拒否も確認した。担当文書の書式検査は成功。既存の混入検査を Node から直接実行し、855ファイル、想定外0件、既知の上流参照3件だった。これは同時作業中の共有ツリーに対する時点の結果で、Git 履歴や配布物の混入保証ではない。アプリの実装を変更していないため、全体検査や実 Electron の新しい成功実績は追加していない。

## 再利用する既存結果

以下は [共有済みの計画05記録](../progress.md#windows-セットアップと配布候補の検証計画05) に基づく。今回の実機再検証ではない。

- 専用試作の日本語セットアップでは、デスクトップショートカットの既定はオフ。選択あり・なし・無人のインストールと Start menu からの起動が成功し、デスクトップには選択ありの場合だけ作成された。
- 選択なしと無人では本体、ショートカット、登録が削除された。選択ありでは本体の削除後にリンク2件と登録2件が残った。試験版と照合した後片付けは実施済みと記録されている。選択ありのアンインストールは未完了。
- 診断版では、本体削除と Windows シェル処理の後、デスクトップ `.lnk` の削除命令の直前で記録が途切れた。起動元の終了コードは0だった。
- 試験用 `Un_A.exe` のブロックや保護ソフト通知の時刻との重なりは記録されている。アクセス先、処理結果、残存項目への影響が未特定のため、保護ソフトが中断の原因とは確定しない。

## GitHub CI と専用候補の区別

現行共有ソースを対象とする [Windows release diagnostic の実行](https://github.com/shijun537/pi-gui-ja-base/actions/runs/45753637219) は成功と共有されている。この記録は専用のショートカット候補の合格を意味しない。

今回は [ワークフロー](../../../.github/workflows/windows-release-diagnostic.yml) と [呼び出される検査](../../../apps/desktop/scripts/verify-windows-release.ps1) を確認した。セットアップ版・ポータブル版の生成、同梱ランタイム依存、7-Zip 検査、無人セットアップによるアプリ本体の配置と形式、ポータブル版の展開が対象になる。日本語の選択画面、選択あり、Start menu からの実起動、再起動、アンインストールの後片付けはこのワークフローでは検証しない。今回 CI の生ログを再取得した実績には追加していない。
